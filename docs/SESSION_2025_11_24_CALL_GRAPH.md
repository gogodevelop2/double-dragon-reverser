| ... | ... | ... | ... |

### 핵심 발견: FUN_1000_293e

```c
void FUN_1000_293e(void)
{
  uint unaff_DI;

  if (unaff_DI < 0x1dc1) {
    FUN_1000_28c0();  // 4번 반복
    FUN_1000_28c0();
    FUN_1000_28c0();
    FUN_1000_28c0();
  } else {
    FUN_1000_28ef();  // 4번 반복
    FUN_1000_28ef();
    FUN_1000_28ef();
    FUN_1000_28ef();
  }
}
```

**분석**:
- **이것이 바로 그래픽 생성 로직의 핵심!**
- DI 레지스터 값(0x1dc1)으로 렌더링 모드 선택
- 4번 반복 = CGA 4개 평면 처리
- 29회 호출 = 매 프레임 실행
