# Double Dragon DOS 메모리 맵

**작성일**: 2025-11-24
**Phase**: 4.6 완료

---

## 🎯 개요

Double Dragon DOS 버전의 완전한 메모리 레이아웃입니다. 164개 함수 분석을 통해 파악한 모든 주요 메모리 주소를 정리했습니다.

---

## 📊 세그먼트 구조

| 세그먼트 | 범위 | 용도 |
|----------|------|------|
| **코드 세그먼트** | 0x1000 | 함수 코드 (164개 함수) |
| **데이터 세그먼트** | 0x1988 | 점프 테이블, 상수, 변수 |
| **스택 세그먼트** | 0x???? | 스택 (동적) |
| **비디오 메모리** | 0xB8000 | CGA 320×200 4색 |

## 🎮 게임 로직

### 객체 시스템

#### 엔티티 배열 1 (플레이어 + 적)
| 주소 | 크기 | 개수 | 용도 |
|------|------|------|------|
| **0x16c6 ~ 0x176e** | 168B | 7개 × 24B | 플레이어(2) + 적(5) |

**구조체 레이아웃** (24 bytes):
```
+0x00 (1B): 객체 타입
+0x01 (1B): 방향 (2=아래, 4=왼쪽, 6=위, 8=오른쪽)
+0x02 (1B): 활성 플래그 (0=비활성, 1=활성)
+0x03 (1B): 깊이 오프셋
+0x04 (2B): ?
+0x06 (2B): 스프라이트 테이블 포인터
+0x08 (2B): X 좌표
+0x0a (2B): Y 좌표
+0x0c (2B): ?
+0x0e (2B): ?
+0x10 (2B): 렌더 데이터 1
+0x12 (2B): 렌더 데이터 2
+0x14 (2B): ?
+0x16 (2B): ?
```

#### 엔티티 배열 2 (투사체/아이템)
| 주소 | 크기 | 개수 | 용도 |
|------|------|------|------|
| **0x3542 ~ 0x35ae** | 108B | 6개 × 18B | 투사체/아이템/이펙트 |

**구조체 레이아웃** (18 bytes):
```
+0x00 (1B): 객체 타입
+0x01 (1B): ?
+0x02 (1B): 활성 플래그
+0x03 (1B): 깊이 오프셋
+0x04 (2B): ?
+0x06 (2B): X 좌표
+0x08 (2B): Y 좌표
+0x0a (2B): ?
+0x0c (2B): ?
+0x0e (2B): 렌더 데이터 1
+0x10 (2B): 렌더 데이터 2
```

## 🔍 주소 계산 방법

### DOS 세그먼트:오프셋 → 선형 주소

```
선형 주소 = (세그먼트 << 4) + 오프셋
         = (세그먼트 × 16) + 오프셋
```

**예시**:
```
1000:18c6 → 0x10000 + 0x18c6 = 0x118c6
1988:16c6 → 0x19880 + 0x16c6 = 0x1af46
```

## 📊 메모리 사용 통계

### 코드 영역
- **함수 개수**: 164개
- **평균 크기**: 약 450 bytes/함수
- **총 코드**: 약 72KB

### 데이터 영역
- **엔티티 배열**: 168 bytes (7×24)
- **투사체 배열**: 108 bytes (6×18)
- **점프 테이블**: 60 bytes (30×2)
- **스프라이트 데이터**: 수 KB (압축 해제 후)

## 🎓 핵심 발견

### 1. 이중 배열 시스템
- **엔티티** (24B): 플레이어 + 적
- **투사체** (18B): 발사체 + 아이템

### 2. 효율적인 메모리 관리
- 작업 버퍼 재사용
- 점프 테이블로 동적 디스패치
- 활성 플래그로 객체 관리

### 3. 스크롤 최적화
- VRAM 포인터 직접 업데이트
- 화면 버퍼 교체 (더블 버퍼링)
- 홀수/짝수 라인 분리 처리

---

## ⚠️ 미확인 영역

아직 완전히 파악하지 못한 메모리 영역:

1. **스테이지 데이터**: 0x3ff4 점프 테이블 이후
2. **사운드 버퍼**: PC 스피커 제어 영역
3. **충돌 검사 데이터**: 히트박스 정보
4. **애니메이션 테이블**: 프레임 시퀀스 데이터
5. **AI 상태**: 적 AI 상태 머신
