## 🔍 스프라이트 처리 체인 상세

### FUN_1000_0b94 - 스프라이트 로딩 함수

**위치**: 1000:0b94
**크기**: 317 bytes
**호출**: FUN_1000_0660 → FUN_1000_0b94

**처리 단계**:

#### 1단계: LZW 압축 해제 (4개 파일)
```c
// 스프라이트 1
DAT_1988_320d = 0x2f9e;  // 출력 버퍼
DAT_1988_320f = 0;
DAT_1988_3213 = 0x1790;  // 파일명 포인터
FUN_1000_1e8a();         // LZW 압축 해제

// 스프라이트 2
DAT_1988_320d = 0x3f9e;
DAT_1988_3213 = 0x179c;
FUN_1000_1e8a();

// 스프라이트 3
DAT_1988_320d = 0x493a;
DAT_1988_3213 = 0x17a8;
FUN_1000_1e8a();

FUN_1000_063e();  // 대기/체크

// 스프라이트 4
DAT_1988_320d = 0x53a0;
DAT_1988_3213 = 0x1786;
FUN_1000_1e8a();
```

**출력 버퍼 주소**:
- 0x2f9e (12190)
- 0x3f9e (16286)
- 0x493a (18746)
- 0x53a0 (21408)

**간격**:
- 1→2: 4096 bytes
- 2→3: 2460 bytes
- 3→4: 2662 bytes

#### 2단계: 비트 재배열 (4번)
```c
FUN_1000_0cd1(0x1988, 0x1988);  // Segment 0x1988
FUN_1000_0cd1();
FUN_1000_0cd1();
FUN_1000_0cd1();
```

**FUN_1000_0cd1 분석**:
- 4개 바이트씩 읽어서 비트 재배열
- planar to chunky 변환
- CGA 비트 평면 처리

#### 3단계: 팔레트 생성
```c
pbVar6 = (byte *)0x8800;  // 팔레트 테이블 시작
uVar5 = 0;
iVar4 = 0x100;  // 256 entries

do {
    bVar3 = 0;
    if ((uVar5 & 0xf) != 0) {
        bVar3 = 0xf;
    }
    if ((uVar5 & 0xf0) != 0) {
        bVar3 = bVar3 | 0xf0;
    }
    *pbVar6++ = ~bVar3;  // 반전된 값 저장
    uVar5++;
    iVar4--;
} while (iVar4 != 0);
```

**팔레트 로직**:
```
입력 i → 출력
0x00 → ~0x00 = 0xFF
0x0F → ~0x0F = 0xF0
0xF0 → ~0xF0 = 0x0F
0xFF → ~0xFF = 0x00
```

#### 4단계: 팔레트 변환 (7번)
```c
FUN_1000_0d64();  // × 7회
```

**FUN_1000_0d64 분석**:
```c
for (int i = 0; i < 256; i++) {
    output[i] = lookup[i >> 4] << 4 | lookup[i & 0xF];
}
```

룩업 테이블을 사용한 256색 변환

## 🔧 LZW 압축 해제 상세

### FUN_1000_1e8a - LZW 래퍼 함수

```c
void FUN_1000_1e8a(void) {
    FUN_1000_1c1e();  // 준비

    // 기존 파라미터 저장
    uVar1 = *(undefined2 *)0x320d;  // 출력 버퍼 오프셋
    uVar2 = *(undefined2 *)0x320f;  // 입력 버퍼 세그먼트?

    // 임시 출력 버퍼 설정
    *(undefined2 *)0x320f = 0;
    *(undefined2 *)0x320d = 0x2949;  // ← 압축 해제 데이터 여기 저장!

    // 파일 오픈 및 압축 해제
    FUN_1000_1df2(uVar2, uVar1);  // DOS INT 21h 파일 I/O
    FUN_1000_5fe0();              // 실제 LZW 압축 해제

    FUN_1000_1c0c();  // 정리
}
```

**중요 주소**:
- **0x320d**: LZW 출력 버퍼 오프셋
- **0x320f**: 입력 버퍼 세그먼트
- **0x3213**: 파일명 포인터
- **0x2949**: 임시 압축 해제 버퍼 (segment 0x1988 기준)

**작동 방식**:
1. 0x320d에 원하는 출력 버퍼 주소 설정 (예: 0x2f9e)
2. 0x3213에 파일명 포인터 설정
3. FUN_1000_1e8a() 호출
4. 내부적으로 0x2949로 임시 변경
5. LZW 압축 해제
6. 0x2949 → 원래 주소(0x2f9e)로 복사?
