## 💡 핵심 발견

### 1. 타일맵 기반 충돌 시스템

**타일맵 구조**:
```
0x4e: 타일맵 베이스 주소
0x46: 타일맵 폭 (바이트 단위)
0x48: 화면 최대 X
0x4a: 화면 최대 Y
```

**좌표 변환**:
- 픽셀 → 타일: `(X/2, Y/4)`
- X는 2픽셀 단위 (CGA 4색 모드)
- Y는 4픽셀 단위

### 2. 나선형 탐색 알고리즘

FUN_1000_3f71에서 호출 패턴:
```c

    // X 방향 이동
    *(int *)0x16a7 += step;

    // 끝에 도달하면 Y 방향으로 전환
    if (--count == 0) {
        *(int *)0x16a9 += step;
        step = -step;    // 방향 반전
        radius++;
    }
}

// 최종 위치 저장

```

**목적**: 캐릭터를 배치할 빈 공간 찾기 (0xFF 타일)

### 4. 메모리 레이아웃

**입력** (작업 버퍼):
- `0x16a7`: X 좌표 (픽셀)
- `0x16a9`: Y 좌표 (픽셀)

**출력**:
- `0x16ad`: 타일 값 (2 bytes)
- `0x16ae`: 충돌 플래그 (0 = 통과, 1 = 충돌)
- `0x16af`: 상태 플래그 (0xb = Y<0, 0xff = 범위밖)

**타일맵 참조**:
- `0x4e`: 타일맵 베이스 주소
- `0x46`: 타일맵 폭
- `0x48`: 최대 X
- `0x4a`: 최대 Y

## 🎯 이 함수의 역할

**Double Dragon의 캐릭터 배치 시스템**:

1. 적 캐릭터가 등장할 때
2. 플레이어가 이동할 때
3. 충돌 감지가 필요할 때

→ **타일맵을 조회**하여:
- 이동 가능한 위치인지 체크
- 지형 타입에 따른 처리 (평지/벽/계단 등)
- 나선형으로 빈 공간 탐색
