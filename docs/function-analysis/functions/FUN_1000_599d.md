## 🖼️ VGA 수직 블랭킹 동기화

### VGA 포트 0x3DA (상태 레지스터)

| 비트 | 의미 |
|------|------|
| bit 0 | Display Enable (1 = 화면 표시 중) |
| bit 3 | **Vertical Retrace** (1 = 수직 블랭킹) |

**수직 블랭킹 (Vertical Blanking)**:
- CRT 모니터가 화면 아래에서 위로 전자빔을 이동하는 시간
- 이 시간 동안에는 화면에 아무것도 그려지지 않음
- **티어링(tearing) 방지**: 이 시간에 VRAM을 업데이트하면 깜빡임 없음

### 전형적인 패턴

```c
// 1. 화면 버퍼 준비 (백버퍼에 그리기)
FUN_1000_599d();  // 백버퍼 → 프론트 버퍼 교체 준비
FUN_1000_599d();  // 또는 더블 버퍼 플립?

// 2. 수직 블랭킹 대기
do {
  vga_status = in(0x3da);
} while ((vga_status & 8) == 0);

// 3. 안전하게 VRAM 업데이트
// (실제 화면 전환은 0x599d 함수 내부?)
```

## 🎮 CGA Mode 4 메모리 구조

CGA는 **2개의 비디오 페이지**를 지원합니다:

| 페이지 | 시작 주소 | 크기 |
|--------|----------|------|
| 0 | 0xB8000 | 16,384 bytes |
| 1 | 0xBC000 | 16,384 bytes |

**페이지 전환**:
- VGA 포트 0x3D8 (Mode Control Register)에 설정
- bit 3: Page Select (0 = 페이지 0, 1 = 페이지 1)

**더블 버퍼링**:
```c
// 프론트 버퍼: 0xB8000 (현재 화면 표시)
// 백 버퍼: 0xBC000 (그리기 작업)

// 그리기 완료 후:
FUN_1000_599d();  // 페이지 전환 준비
FUN_1000_599d();  // 실제 전환?

// VGA 수직 블랭킹 대기
wait_for_vblank();

// 이제 0xBC000이 화면에 표시됨
// 다음 프레임은 0xB8000에 그리기 시작
```
