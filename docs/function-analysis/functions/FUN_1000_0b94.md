### 2단계: 비트 재배열 (× 4)

```c
FUN_1000_0cd1(0x1988, 0x1988);  // 첫 호출만 파라미터
FUN_1000_0cd1();
FUN_1000_0cd1();
FUN_1000_0cd1();
```

**기능**: CGA Planar → Chunky 변환
- 4개 바이트(4 planes) → 4개 바이트(8 pixels, 4-bit each)
- 각 바이트의 같은 비트 위치를 모아서 재배열

**구현 상태**: ✅ **완료** (cga_planar_to_chunky.c)

### 3단계: 팔레트 생성

```c
pbVar6 = (byte *)0x8800;  // 팔레트 테이블 시작
uVar5 = 0;
iVar4 = 0x100;  // 256 entries

do {
    bVar3 = 0;
    if ((uVar5 & 0xf) != 0) {     // 하위 4비트 체크
        bVar3 = 0xf;
    }
    if ((uVar5 & 0xf0) != 0) {    // 상위 4비트 체크
        bVar3 = bVar3 | 0xf0;
    }
    *pbVar6++ = ~bVar3;  // 반전된 값 저장
    uVar5++;
    iVar4--;
} while (iVar4 != 0);
```

**팔레트 생성 규칙**:
```
입력 i → 중간 값 → 출력
0x00 → 0x00 → ~0x00 = 0xFF
0x01 → 0x0F → ~0x0F = 0xF0
0x10 → 0xF0 → ~0xF0 = 0x0F
0x11 → 0xFF → ~0xFF = 0x00
0x55 → 0xFF → ~0xFF = 0x00
0xAA → 0xFF → ~0xFF = 0x00
```
