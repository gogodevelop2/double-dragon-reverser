## 📋 목적

**CGA Planar 비트맵을 Chunky 형식으로 변환**.
- 4개 바이트 (4 planar planes) 입력
- 4개 바이트 (8 pixels, 4-bit each) 출력
- 각 바이트의 같은 비트 위치를 모아서 재배열

### 비트 재배열 상세

**입력** (4 bytes, planar):
```
Plane 0: b7 b6 b5 b4 b3 b2 b1 b0
Plane 1: b7 b6 b5 b4 b3 b2 b1 b0
Plane 2: b7 b6 b5 b4 b3 b2 b1 b0
Plane 3: b7 b6 b5 b4 b3 b2 b1 b0
```

**출력** (4 bytes, chunky):
```
Word 0: [P0[7]P1[7]P2[7]P3[7]] [P0[6]P1[6]P2[6]P3[6]] | ...
Word 1: [P0[3]P1[3]P2[3]P3[3]] [P0[2]P1[2]P2[2]P3[2]] | ...
```

각 픽셀 = 4비트 (P0~P3의 해당 비트)

## 💻 구현 (C)

```c
void cga_planar_to_chunky(uint8_t *data, size_t num_groups) {
    for (size_t i = 0; i < num_groups; i++) {
        uint8_t *ptr = data + (i * 4);

        // 4바이트 읽기
        uint8_t plane0 = ptr[0];
        uint8_t plane1 = ptr[1];
        uint8_t plane2 = ptr[2];
        uint8_t plane3 = ptr[3];

        // 2개 워드(4바이트) 출력
        uint16_t word0 = 0;
        uint16_t word1 = 0;

        // 각 비트 위치에서 4개 plane의 비트를 추출하여 재배열
        for (int bit = 7; bit >= 0; bit--) {
            int b0 = (plane0 >> bit) & 1;
            int b1 = (plane1 >> bit) & 1;
            int b2 = (plane2 >> bit) & 1;
            int b3 = (plane3 >> bit) & 1;

            int pixel = (b0 << 3) | (b1 << 2) | (b2 << 1) | b3;

            if (bit >= 4) {
                word0 = (word0 << 4) | pixel;
            } else {
                word1 = (word1 << 4) | pixel;
            }
        }

        // Little-endian으로 출력 (in-place)
        ptr[0] = word0 & 0xFF;
        ptr[1] = (word0 >> 8) & 0xFF;
        ptr[2] = word1 & 0xFF;
        ptr[3] = (word1 >> 8) & 0xFF;
    }
}
```

## 🔍 발견 사항

### CGA Mode 4 구조

**320x200, 4색**:
- 2 bits per pixel
- 4개 색상 (팔레트 0 또는 1)
- Planar 방식: 각 색상 비트가 분리

**Planar vs Chunky**:
- **Planar**: 색상 비트가 분리된 평면에 저장 (저장 효율)
- **Chunky**: 픽셀 데이터가 연속으로 저장 (렌더링 효율)

### In-place 변환

- 입력: 4 bytes
- 출력: 4 bytes (같은 위치에 덮어쓰기)
- 메모리 절약

### 처리 속도

**LINDA.dat 테스트**:
- 237 bytes = 59 그룹 (4바이트씩)
- 변환 시간: < 1ms (현대 CPU)
- 원래 DOS: 수십 ms 추정
