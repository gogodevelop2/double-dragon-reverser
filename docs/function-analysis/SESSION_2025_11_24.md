### 6. CGA 그래픽 시스템

#### 16-평면 인터리브 포맷

```
원본 데이터 (인터리브):
  [plane_0][plane_1][plane_2]...[plane_15]
   ↓ 0x50  ↓ 0x50  ↓ 0x50     ↓ 0x50

변환 후 (청크):
  [p0,p1,p2...p15][p0,p1,p2...p15]...
```

**FUN_1000_0786** (435 bytes):
- 입력: DAT_1988_003a (인터리브)
- 출력: 0x7800 (청크)
- 16개 평면 × 4픽셀씩 처리
- 130회 반복 (일반 모드) 또는 240회 (특수 모드)

**FUN_1000_09d1** (196 bytes):
- 다른 모드 (EGA?) 비트 변환
- 비트별 추출 및 팩킹

## 🎓 배운 교훈

### ✅ 성공한 방법

1. **차근차근 함수 읽기**
   - 추측하지 않고 디컴파일된 코드 한 줄씩 읽기
   - 호출 관계를 따라가며 이해

2. **크기별로 정렬하여 중요 함수 찾기**
   - `wc -l *.c | sort -rn`
   - 큰 함수 = 실제 로직

3. **메인 루프부터 시작**
   - entry → 초기화 → 메인 루프
   - 매 프레임 실행 흐름 이해

### ❌ 실패한 접근

1. **디스패치 테이블 내용 추측**
   - 메모리 덤프해도 Ghidra가 인식 못 한 함수들
   - 실제로 읽어야 알 수 있음

2. **"Blit 함수 찾기"에 집착**
   - 여러 레이어의 디스패처 체인
   - 전체 구조 이해 없이는 찾기 어려움
