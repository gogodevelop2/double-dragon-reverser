## 🔬 기술적 발견

### 1. CGA 4-Planar 렌더링
FUN_1000_5c0a가 증명:
```
Offset 0x0000 - Plane 0 (Cyan)
Offset 0x1000 - Plane 1 (Magenta)
Offset 0x2000 - Plane 2 (White bit 0)
Offset 0x3000 - Plane 3 (White bit 1)
```

### 2. 원형 버퍼 스크롤링
```c
offset = (offset + delta & 0x3fff) + 0xb0d0;
```
16KB 순환 버퍼로 무한 스크롤 구현!

### 3. 폰트 렌더링 최적화
