## 🎓 배운 점

### 1. MCP vs 직접 라이브러리 사용

- **MCP 서버**: LLM 통합에 최적화, 하지만 배치 작업에는 오버헤드
- **pyghidra 직접 사용**: 안정적, 빠름, 프로그래매틱 제어 가능

### 2. Ghidra 프로젝트 재사용

- 한 번 분석하면 여러 번 활용 가능
- 심볼, 함수, 크로스 레퍼런스 모두 보존
- headless 모드로 자동화 용이

### 3. DOS 바이너리 특성

- 16비트 세그먼트 주소 (seg:offset)
- near/far call 구분
- 직접 메모리 접근 (`*(char *)(address)`)
- 글로벌 변수 많음 (DAT_xxxx_xxxx)
