## 🏆 주요 발견 사항

### 1. 완전한 렌더링 파이프라인 파악

**5단계 파이프라인 발견**:
```
1. FUN_1000_029a: Depth-sorted 렌더링 루프
   └─> 객체 배열을 깊이별로 정렬하여 Z-ordering

2. FUN_1000_48e0: 렌더링 디스패처
   └─> 0x18c6 점프 테이블 (30개 엔트리)

3. FUN_1000_293e: 모드 선택 (29회 호출)
   └─> DI < 0x1dc1 ? Mode 1 : Mode 2

4. FUN_1000_28c0/28ef: Blit 함수 × 4
   └─> CGA 4-plane 개별 처리

5. 비디오 메모리 출력 (0xB8000)
```

**핵심 코드**:
```c
// Depth-sorted 렌더링 (FUN_1000_029a)
do {
    for (projectile in projectiles) {
        if (active && depth == current_depth) {
            FUN_1000_48e0();  // 디스패처
        }
    }
    for (entity in entities) {
        if (active && depth == current_depth) {
            FUN_1000_48e0();
        }
    }
    depth++;
} while (depth <= max_depth);

// Blit opaque (FUN_1000_28c0)
for (int line = 0; line < 16; line++) {
    *dst = *src;
    dst += stride + 2;
    src++;
}

// Blit transparent (FUN_1000_28ef)
for (int line = 0; line < 16; line++) {
    *(dst & mask) = *src;  // AND masking
    dst = (dst + stride + 2) & mask;
    src++;
}
```

### 2. 메모리 맵 완전 분석

**50+ 주소 파악**:

#### 객체 시스템
- **0x16c6 ~ 0x176e**: 엔티티 배열 (7개 × 24B)
  - 플레이어 2명 + 적 5명
  - 구조체: 타입, 방향, 활성, 좌표, 스프라이트 포인터

- **0x3542 ~ 0x35ae**: 투사체 배열 (6개 × 18B)
  - 발사체, 아이템, 이펙트

#### 렌더링 제어
- **0x18c6**: 렌더링 점프 테이블 (30개 × 2B)
- **0x18d0**: 함수 포인터 (FUN_1000_8135용)
- **0x1dc1**: 렌더링 모드 임계값
- **0x16c0/16c2**: 깊이 레이어 범위

#### 스크롤 시스템
- **0xf396**: X 스크롤 위치
- **0xf398**: Y 스크롤 위치
- **0xf38c**: VRAM 오프셋 포인터
- **0xf38e**: Scanline 오프셋

### 3. 점프 테이블 시스템

**5개 점프 테이블 발견**:

| 주소 | 엔트리 | 용도 | 사용 함수 |

| 0x18d0 | ?개 | 함수 디스패처 | FUN_1000_8135 |
| 0x1319 | ?개 | 타일맵 디스패처 | FUN_1000_12c0 |
