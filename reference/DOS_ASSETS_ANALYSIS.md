# DOS 게임 에셋 분석

더블 드래곤 DOS 버전 파일 구조 및 에셋 분석 문서

## 파일 카테고리

### 실행 파일
- **DDMAIN.EXE** (103K): 메인 게임 실행 파일
- **DUAL.EXE** (547B): 듀얼 플레이어 모드 유틸리티
- **SHOW.EXE** (836B): 이미지 표시 유틸리티

### 배치 파일
- **DRAGON.BAT**: 게임 실행 스크립트

### 그래픽 리소스
- **LDSCRN.CGA** (6.8K): 로딩 화면 (CGA 그래픽)
- **LOAD.CGA** (7.2K): 로드 화면
- **CHARSET.BIN** (276B): 문자 세트

### 설정 파일 (.SCR, .PIF)
- **JOYKEY.SCR** (4.8K): 조이스틱/키보드 설정
- **ONETWO.SCR** (4.9K): 1인/2인 플레이 설정
- **VIDMOD.SCR** (4.7K): 비디오 모드 설정
- **DDMAIN.PIF**: Windows 호환성 설정
- **DRAGON.PIF**: Windows 실행 설정

## 에셋 추출 계획

### 1단계: 그래픽 추출
- [ ] CGA 그래픽 파일 (.CGA) → PNG 변환
- [ ] 스프라이트 파일 (.EG1, .EG2) → 스프라이트 시트 추출
- [ ] 레벨 배경 (.PC1) → 배경 이미지 추출

### 2단계: 데이터 분석
- [ ] 레벨 구조 분석 및 JSON 변환
- [ ] 캐릭터 애니메이션 프레임 분석
- [ ] 적 배치 및 AI 패턴 분석

### 3단계: 사운드 (추가 조사 필요)
- [ ] DOS 버전에 포함된 사운드 확인
- [ ] PC 스피커 사운드 → 웹 오디오 변환

## 파일 포맷 참고사항

- **.EG1/.EG2**: 커스텀 스프라이트 포맷 (리버스 엔지니어링 필요)
- **.PC1**: 레벨 데이터 포맷 (배경 + 오브젝트 배치)
- **.NW1~.NW5**: 미니 캐릭터 애니메이션 프레임
- **.CGA**: CGA 4색 그래픽 포맷 (320x200, 4색)
